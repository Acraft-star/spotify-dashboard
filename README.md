# 🎵 Spotify Data Analysis

## 📌 Project Title

**Spotify Data Analysis**

An interactive **Power BI dashboard** built to analyze Spotify music data and understand trends related to artists, songs, popularity, albums, song duration, and yearly performance.

--

## 📊 Project Overview

This project presents an interactive Spotify analytics dashboard developed using **Microsoft Power BI**. The dashboard transforms raw Spotify music data into meaningful visual insights that help users explore artists, songs, albums, popularity, duration, and yearly trends.

The dashboard contains multiple pages including:

* 🏠 Home
* 📊 Overview
* 🎤 Artists
* 🎵 Songs

Users can interact with the dashboard to explore different aspects of Spotify music data.

---

## 🎯 Business Problem

Spotify contains a large amount of music data with information about songs, artists, albums, popularity, release years, and song duration.

Analyzing this data manually can make it difficult to identify:

* Which artists have the most songs
* Which songs are most popular
* How song popularity changes over time
* Differences between albums and singles
* Song duration patterns
* Year-wise music trends

The objective of this dashboard is to convert the raw Spotify dataset into an easy-to-understand interactive analytical report.

---

## 🎯 Goal of the Dashboard

The main goals of the dashboard are to:

* Analyze artist and song performance
* Identify popular artists and songs
* Understand song popularity trends
* Compare albums and singles
* Analyze song duration
* Compare music data from **2023 and 2024**
* Provide interactive filtering and exploration
* Present important KPIs and trends in a visually appealing way

---

## 🛠️ Tech Stack

The dashboard was built using the following tools and technologies:

* **Power BI Desktop** – Dashboard development and visualization
* **Power Query** – Data cleaning and transformation
* **DAX (Data Analysis Expressions)** – Measures and calculations
* **File Format** – `.pbix`
* **Data Visualization** – Power BI charts, cards, tables and interactive visuals

---

## 📂 Data Source

The project uses a Spotify music dataset containing approximately:

* **28,000+ rows**
* **15 columns**

The dataset contains information related to songs, artists, albums, popularity, release dates, duration, album type and other Spotify-related attributes.

### Example Data Fields

Some examples of the data fields include:

* Song Name
* Artist
* Popularity
* Duration
* Album Type
* Release Date
* Year
* Position
* Album Information
* Explicit / Non-Explicit Status
